# Shasky Ya

Aplicacion desarrollada para facilitar la busqueda de maestros y servicios del hogar cercanos.

## Enfoque

Shasky Ya permite buscar un oficio, revisar maestros cerca del domicilio, ver su reputacion en escala chilena, abrir un chat, llamar y coordinar costos o visitas.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies: `npm install`
2. Run the app: `npm run dev`
